Om sensorerne

Sensorerne måler, hvor mange mennesker der går forbi dem, uanset retning, ved hjælp af temperaturmåling. Dataene kan hjælpe kommunen med at forstå, hvor ressourcer bør placeres, og understøtte bedre beslutninger.

Eksempel på sensorplaceringer og persontælling via temperaturmåling.

    Om projektet

    Prototypen er udviklet som et studieprojekt på Roskilde Universitet med Gate21 som case. Formålet er at vise, hvordan data fra persontællende sensorer kan gøres overskuelige for kommuner, så de lettere kan se, hvor der er mest aktivitet, og planlægge derefter.

    Bemærk: sensordataene på siden er eksempeldata.
